## Contenido

### `estructuras-de-datos/polaca-inversa`

Programa en C++ que valida una expresión infija de forma recursiva, la convierte
a notación polaca inversa con *shunting-yard* y construye un árbol de expresión
para mostrar sus recorridos y dibujarlo en la consola.

Ver [su README](estructuras-de-datos/polaca-inversa/README.md).
